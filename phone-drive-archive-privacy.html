Phone Drive Archive — Privacy Policy

Effective 17 November 2026 · Developer: 윤정식 (individual) · Contact: nataws88@gmail.com

Summary. Phone Drive Archive is an internal tool used only by its developer to manage the developer's own YouTube channels and Google Drive files. It uses YouTube API Services. It does not sell, share, or advertise with any data, and it keeps data only on the developer's own phone.

1. YouTube API Services and Google

This tool uses YouTube API Services (YouTube Data API, YouTube Analytics API, YouTube Reporting API). By using the tool you agree to this Privacy Policy and agree to be bound by the YouTube Terms of Service. Google's own use of data is governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Who uses the tool

Only the developer. The tool is not distributed or offered to the public, and only the developer's own Google accounts authorize it through Google OAuth 2.0. The tool never asks for or stores a Google password.

3. Information the tool accesses

Only data of the YouTube channels and Google account that the developer has authorized:

  • Channel and video information — channel ID and name; video titles, descriptions, tags, language, privacy and scheduled-publishing status, altered or synthetic content disclosure status, thumbnails, caption tracks, and playlists.
  • Channel statistics — views, watch time, subscribers, traffic sources, audience retention and estimated revenue of the developer's own channels (YouTube Analytics and Reporting APIs).
  • OAuth tokens issued by Google, so the tool can act on the developer's own channels.
  • Google Drive files that the developer uploads to or downloads from the developer's own Drive (work files and videos).

The tool does not access other people's private data, contacts, location, or device identifiers.

Use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. How the information is used

  • To upload and manage the developer's own videos, captions, thumbnails and playlists.
  • To create private reports about the developer's own channels for the developer.
  • To archive and restore the developer's own work files.

The information is not used for advertising, profiling, or any purpose other than the developer's own channel work.

5. Sharing

The information is not shared, sold, or disclosed to any third party. Data is exchanged only with Google (YouTube and Google Drive APIs), and only to carry out the developer's own requests.

6. Storage, security, retention and deletion

  • OAuth tokens and API data are stored only on the developer's own phone, in files that only the device owner can read. Tokens are kept only while the developer uses the tool for the purposes described here.
  • All YouTube API data stored by the tool, including statistics, is deleted or refreshed within 30 calendar days. Daily report folders older than 30 days are deleted automatically. The tool refreshes its authorization every day, which confirms at least every 30 days that access has not been revoked.
  • Revoking from within the tool (the youtube-api revoke command) revokes the token with Google right away and deletes the token and all YouTube API data obtained with it (including statistics) immediately, and in any case within 7 calendar days of the revocation.
  • Revoking on Google's security settings page (section 8): the tool detects that its token can no longer be refreshed and deletes all related YouTube API data (including statistics) as soon as possible and within 30 calendar days of the revocation.
  • Deletion can also be requested at any time by email to nataws88@gmail.com; requested data is deleted within 7 calendar days.

7. Cookies, device storage and third parties

The tool itself does not place cookies or read device identifiers, has no advertising, and does not let any third party serve content or ads or collect information through it. These web pages are static pages hosted on GitHub Pages; GitHub may keep standard server logs under its own policy.

8. Revoking access

In addition to the deletion methods above, you can revoke this tool's access to your Google and YouTube data at any time on the Google security settings page: https://security.google.com/settings/security/permissions.

9. Children

The tool is not directed at children and does not collect information from children.

10. Changes and contact

If this policy changes, the updated version will be posted on this page with a new effective date. Questions: nataws88@gmail.com.
